# Forex Opportunity Radar

Automatically discovers monetization opportunities in forex, prop trading, gold trading, and trading psychology.

## Features

- Fetches latest Google News RSS feeds.
- Discovers emerging forex trends.
- Identifies potential SaaS opportunities.
- Runs automatically using Render Cron Jobs.
